На этой сетке разница убывает с температурой. По диаметру она убывает на всей сетке для 100 мл/ч и на большей части сетки для 200 и 300 мл/ч. Локальные максимумы при 200 и 300 мл/ч смещены внутрь диапазона диаметров. Разница времени меняется в противоположном направлении.

На сетке разница массовых расходов составляет +1.115…+10.541 %. Предварительная оценка порядка 1–11 % согласуется с рассчитанным диапазоном.
Знак различия сохраняется по всей сетке. DGM даёт больший массовый расход и меньшее время, поскольку время обратно пропорционально расходу.

## Воспроизведение

Входные CSV создаёт `study.clj` в полном прогоне с `--dense-csv`. Для опубликованного сравнения использованы сетки этапа 27.5. Версию решателя проверили по исходному коду, базовому режиму и угловым точкам. [Команды расчёта сеток](DGM.md#reference-and-reproduction)

```powershell
python -X utf8 scripts/cpim-verification/compare.py target/cpim-verification/cpim-dense.csv target/cpim-verification/dgm-dense.csv
```
