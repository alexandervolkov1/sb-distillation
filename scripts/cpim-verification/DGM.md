# Independent numerical verification of DGM

## Reference and reproduction

The independent reference integrates total pressure and the Sb₄ mole fraction in the distance from the outlet. It uses SciPy DOP853 with dense output and Brent's method for shooting. The DGM pressure derivative is evaluated directly from the summed species equations using both Knudsen flux terms and the denominator `1 + beta1 + beta2`. The species equation gives the mole-fraction derivative through the product rule. The CPIM reference and the common transport and operating inputs come from the original study. [DGM theory at e6a744f](https://github.com/alexandervolkov1/sb-distillation-theory/blob/e6a744f3a66f7a58dcb99a81f7a8655fa8bdacf6/main.typ#L1156-L1364) · [Original CPIM study](README.md) · [Reference implementation](reference.py)

The standard and tight SciPy settings are `(rtol, atol_p, xtol_N1) = (2e-11, 2e-12 Pa, 2e-14 mol/(m²·s))` and `(2e-13, 2e-14 Pa, 2e-16 mol/(m²·s))`. The absolute mole-fraction tolerance is `atol_p / p1_sat`. All 189 points were solved at both settings for each model before using the tight results below.

| Model | Max relative flux change | Max Sb₄ profile change, Pa | Max H₂ profile change, Pa |
| --- | ---: | ---: | ---: |
| CPIM | 7.82e-13 | 1.28e-9 | 1.21e-9 |
| DGM | 1.97e-12 | 2.93e-9 | 2.75e-9 |

Run the following commands from the repository root with Python 3.14.6, NumPy 2.5.5 and SciPy 1.18.1. The ordinary Clojure tests read the committed baseline fixtures and require no Python installation. The dense CSVs contain per-model scalar results in SI for later use. [CPIM fixture](../../test/fixtures/cpim-reference.edn) · [DGM fixture](../../test/fixtures/dgm-reference.edn)

```powershell
New-Item -ItemType Directory -Force target/cpim-verification | Out-Null
python -m pip install scipy==1.18.1 numpy==2.5.5
$out = 'target/cpim-verification'
foreach ($model in 'cpim', 'dgm') {
  python scripts/cpim-verification/reference.py --model $model --fixture "$out/$model-fixture.edn" --study "$out/$model-reference.edn"
  clojure -M scripts/cpim-verification/study.clj "$out/$model-reference.edn" "$out/$model-pressures.csv" --model $model --full-grid --dense-csv "$out/$model-dense.csv"
  python scripts/cpim-verification/reference.py --model $model --pressures "$out/$model-pressures.csv"
}
clojure -M:test
```

The DGM baseline fixture and reference grid regenerated byte for byte. The regenerated CPIM grid agrees entry by entry with the archived grid. With LF line endings, the DGM baseline fixture SHA-256 is `278d7522a0a6968f9e9d41cb9dd06aa3f5fe7c8b3399cb3d944e034dcc2f4f08` and the full DGM reference grid SHA-256 is `d38905308416a334986b8b4bae7aab50cc5f3c5e8a67db6213b0926d21727dce`. The step and residual tolerances in production remain the accepted `1e-8 Pa`, `1e-6` and `1e-3 Pa`.

## Limiting boundary-value problems

Both models approach the analytic molecular solution with linear partial pressures. At 973.15 K and outlet H₂ pressure 0.2 Pa, the diameter decreases from 10 to 0.1 µm and the feed scales as diameter cubed to keep the molecular hydrogen pressure rise fixed. In the continuum tests, the diameter stays 10 mm, feed stays 200 ml/h, and the outlet pressure grows from 100 to 10,000 Pa.

The limiting pressure equation uses the leading continuum resistance. The CPIM reference removes Knudsen offsets from the composition equation. The DGM reference drops the 1 from the denominator `1 + beta1 + beta2` and retains the finite viscous `beta_i G` and Knudsen contributions in the partial-pressure balance. Each limiting comparison solves its model's asymptotic boundary-value problem. [Theory and limiting equations](https://github.com/alexandervolkov1/sb-distillation-theory/blob/e6a744f3a66f7a58dcb99a81f7a8655fa8bdacf6/main.typ#L1310-L1345)

| Limiting series | Case | CPIM relative flux error vs limit | DGM relative flux error vs limit |
| --- | ---: | ---: | ---: |
| Molecular | 10 µm | 5.59e-3 | 6.07e-3 |
| Molecular | 1 µm | 5.58e-4 | 6.06e-4 |
| Molecular | 0.1 µm | 5.58e-5 | 6.06e-5 |
| Continuum | 100 Pa | 5.26e-2 | 3.61e-2 |
| Continuum | 1000 Pa | 2.69e-2 | 2.16e-3 |
| Continuum | 10000 Pa | 2.78e-3 | 2.21e-5 |

DGM station differences from the molecular limit decreased from `0.0974 / 0.172 Pa` to `0.000975 / 0.00172 Pa`. Its differences from the continuum approximation decreased from `2.44 / 7.03 Pa` to `0.000520 / 0.000669 Pa`. Against the full SciPy reference on the six synthetic DGM cases, the maximum relative flux error was `2.95e-9` and the maximum station pressure error was `1.34e-6 Pa`.

## Performance

All three configurations ran serially on the same AMD Ryzen 5 6600H with Windows 10 Pro x64 and Temurin `25.0.4.1+1-LTS`. The same benchmark source and 189 problems in the same order were used for each fresh JVM. The heap settings were `-Xms256m -Xmx512m`. Each JVM ran five untimed grid passes followed by two measured passes. The three cycles rotated the order of the configurations. The timers bracket only the call to `solve`. Input preparation, success checks, aggregation, serialization and hashing are outside the timed interval. The pre-refactor implementation uses the original CPIM entry point. The current implementations use the public model-selecting entry point with identical numerical defaults. [Benchmark source](benchmark.clj)

| Configuration | Six pass means, ms per solve | Overall mean, ms | Max single solve, ms |
| --- | --- | ---: | ---: |
| CPIM before refactor (`818e091`) | 15.433, 15.429, 15.653, 15.979, 15.773, 15.736 | 15.667 | 26.777 |
| CPIM after refactor (`b820561` sources) | 19.044, 18.968, 19.242, 19.249, 19.425, 19.525 | 19.242 | 24.902 |
| DGM (`b820561` sources) | 16.801, 17.133, 15.650, 16.027, 16.576, 16.644 | 16.472 | 31.594 |

Each configuration contributes 1134 timed solves. The mean CPIM solve time increased by 22.8% after the refactor in this benchmark. These measurements include the cost of allocations and garbage collection during `solve`. They establish the total runtime difference. Component-level profiling was outside this study.

To reproduce the benchmark from the repository root, extract the pre-refactor sources from Git and run the same harness from each source directory.

```powershell
$root = (Get-Location).Path
$out = Join-Path $root 'target/cpim-verification'
New-Item -ItemType Directory -Force $out | Out-Null
$before = Join-Path $out 'before-refactor'
$zip = Join-Path $out 'before-refactor.zip'
$runner = Join-Path $root 'scripts/cpim-verification/benchmark.clj'
if (-not (Test-Path $before)) {
  git archive --format=zip --output="$zip" 818e0918928ce83c4514fef654690e51d3a17176
  if ($LASTEXITCODE -ne 0) { throw 'Archive failed' }
  Expand-Archive -LiteralPath $zip -DestinationPath $before
}
foreach ($order in 'before cpim dgm', 'dgm before cpim', 'cpim dgm before') {
  foreach ($mode in $order.Split(' ')) {
    if ($mode -eq 'before') { $location = $before } else { $location = $root }
    Push-Location $location
    try {
      clojure -J-Xms256m -J-Xmx512m -M $runner $mode 5 2
      if ($LASTEXITCODE -ne 0) { throw "Benchmark failed for $mode" }
    } finally { Pop-Location }
  }
}
```

## Verification status

`clojure -M:test` passed 97 tests and 1860 assertions. The DGM baseline is checked against the committed SciPy fixture, and the CPIM convergence output regenerated identically. No solver failures were observed on the stated grids. Transport parameters, flow reference conditions, gauge calibration, and the saturation correlation still limit physical inference. Experimental validation of antimony transfer rates remains open.
